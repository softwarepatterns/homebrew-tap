# homebrew-tap

Public distribution channel for **forgejo** — binaries, checksums,
signatures, and packaging metadata only. Never source (closed source,
public binaries).

## Install

### macOS (Homebrew)

    brew tap softwarepatterns/tap
    brew trust softwarepatterns/tap
    brew install forgejo-cli

The formula is generated by the release pipeline from the real checksums —
never hand-written.

### Linux (amd64 / arm64, `.deb`)

    curl -sSL https://github.com/softwarepatterns/homebrew-tap/raw/main/install-deb.sh | bash -s forgejo

Pin a version for reproducibility:

    curl -sSL https://github.com/softwarepatterns/homebrew-tap/raw/main/install-deb.sh | bash -s forgejo 0.2.0

`install-deb.sh` verifies the release's `SHA256SUMS` against the signing key
in this repo (`public.gpg`) and the package's own checksum before it
installs anything.
